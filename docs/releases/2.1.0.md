**Beluga 2.1.0: at home on Windows and Linux.**

- **Folders and files open on Windows**: Show in File Explorer selects the file, and opening a folder, a log or a run's outputs goes to the right place.
- **Words for your computer**: File Explorer and Ctrl on Windows, Files and Ctrl on Linux, Finder and ⌘ on a Mac. A friend's computer is their computer, whatever it runs.
- **Terminals on Windows**: PowerShell and cmd tabs stay open, and Git Bash gets the login shell it expects.
- **Claude on Windows**: it can send you files from any folder, finds Codex and your editor, loads the project's skills, and opens sub-agents' screenshots and logs.
- **Friends on Windows**: commands a friend runs keep the settings Windows needs, and run in Git Bash when you have it. Sharing a folder works.
- **Pictures**: pasting an image works on Windows and Linux, and the phone gets thumbnails and project icons from any computer.
- **Notifications**: they make a sound on Windows and Linux, and Notification Settings opens Windows' own.
- **Quitting and updating on Windows**: Beluga leaves the room cleanly and stops what it started, and an update stops it first so the installer can put the new one in place. Updates install while you're away, as on a Mac.
- **Linux**: the .deb and .rpm no longer clash with your system's Node, Beluga finds the tools your shell's profile adds (nvm, ~/.local/bin), a beluga:// link opens Beluga, and the tray whale shows on dark bars.
- **Battery**: the power saver knows when a Windows laptop or a Linux one runs on battery.
- **Work pages**: Tasks, Issues, Actions and Plans offer Add a Project… when there's none yet.
- **Safer opening**: programs, installers and scripts are shown in their folder instead of run, on every system.

The phone app is 2.1.0 too: it updates by itself.
